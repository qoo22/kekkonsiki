PROJECTION

  • 画面は16:9固定。どの解像度でも同じ見え方になります
  • 「全画面で投影」でスクリーン部分だけが全画面に。司会メモは映りません
  • 全画面のままキーボードで操作できます（下記）
  • PCを拡張ディスプレイにしてブラウザをプロジェクタ側へ移し、そこで全画面にするのが理想。手元のPCには何も映りませんので、進行はキー操作で

CONTROL

  • A〜D（1〜4でも可）で選択 → Enterでファイナルアンサー → Enterで次の問題
  • Fで全画面の切り替え、Escでオーバーレイを閉じる
  • ライフラインは画面右上をクリック（1回ずつ使用可）

PROGRAM

  • 掴み（30秒）「本日最後の余興です。全10問、賞金は……出ません」
  • ルール（30秒）4択・全員参加・指でA〜Dを出してもらう
  • 出題（12分）1問1分強。迷ったら即答えを開ける
  • 締め（1分）最終問題の答えからそのまま拍手へ
  • 10分に縮めるならQ5（決まり文句）とQ9（未来予知）を飛ばす

REWRITE

司会卓に「要ヒアリング」と出る5問（Q1・Q4・Q6・Q7・Q8）は二人にまつわる問題です。前日までに本人へ答えを聞いて選択肢を作り替えてください。残り5問はそのまま使えます。

コツは実話1つ＋もっともらしい嘘3つ。嘘の3つも本人らしさが出るものにすると、会場が本気で迷います。
